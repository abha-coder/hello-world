# AbleCode AI

AbleCode AI is an accessible software development environment that helps developers create accessible software.

## Features

- Code View
- AI View
- Debugger
- Accessible code generation
- Voice dictation
- Start Dictation
- Stop Dictation
- VoiceOver-friendly navigation
- Live code preview
- Copy code
- Download code
- Progressive Web App support

## Project Files

- `index.html` — Main application
- `manifest.webmanifest` — PWA configuration
- `sw.js` — Service worker
- `README.md` — Project documentation

## Accessibility

AbleCode AI is designed to be usable with assistive technologies such as Apple VoiceOver.

The interface includes:

- Semantic HTML
- Keyboard navigation
- Visible focus indicators
- ARIA labels
- Live announcements
- Logical focus management
- Reduced-motion support
- Accessible buttons and form controls

## How to Run

Open the project through GitHub Pages.

In GitHub:

1. Open **Settings**.
2. Select **Pages**.
3. Choose **Deploy from a branch**.
4. Select the `main` branch.
5. Select `/ (root)`.
6. Select **Save**.

After deployment, open the GitHub Pages address in Safari.

## Using AbleCode AI

### Code View

Write and edit your code, save it, run the preview, copy the code, or download it.

### AI View

Describe the software you want to create and use **Generate Accessible Code**.

You can also use dictation to describe your idea.

### Debugger

Run the project and inspect errors.

The debugger can also explain an error and suggest a possible fix.

## VoiceOver

AbleCode AI is designed so that the main controls can be navigated using VoiceOver.

Use Safari on iPhone and turn on VoiceOver to test the application.

## Project Status

This is the MVP version of AbleCode AI.

The current AI generation feature uses a local demonstration generator. A future version can connect the AI View to a secure AI backend.

## License

This project is currently an MVP/prototype.
